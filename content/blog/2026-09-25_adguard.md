---
title: "AdGuard is now an official app"
date: 2026-09-25
---

AdGuard Home is now available as an [official Quollix app]({{< relref "docs/introduction/apps.md" >}}). It provides network-wide DNS filtering for advertisements and trackers and can create local DNS records for Quollix servers running inside a LAN. See the [AdGuard app documentation]({{< relref "docs/usage/installed-apps/adguard.md" >}}) for installation prerequisites and setup instructions.
