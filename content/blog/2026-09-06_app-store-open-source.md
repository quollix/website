---
title: "App Store source code published"
date: 2026-09-13
---

The [App Store]({{< relref "docs/project/app-store/_index.md" >}}) source code is now published on GitHub under the MIT License. App maintainers can request to get an account and distribute app definitions for Quollix administrators to install. Now, the App Store also supports [migration checkpoints]({{< relref "docs/project/app-store/migration-checkpoints.md" >}}), which help maintain stable update paths across app versions.
