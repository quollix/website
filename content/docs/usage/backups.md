title: "Backups"
---

{{< ui-location "Apps" "Backups" >}}

Once a [backup server]({{< relref "docs/usage/settings/backup-server.md" >}}) has been configured in the settings, users can create backups of each app on the [Installed apps]({{< relref "docs/usage/installed-apps/_index.md" >}}) page. The Backups page allows you to view and restore backups of apps.

{{< alert title="Note" color="warning" >}}
Restoring an app backup will erase any previously existing app data that was not backed up. Consider creating a current backup before restoring an old backup.
{{< /alert >}}

Deleting a backup does not affect the currently running app.
