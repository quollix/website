title: "Repository Map"
---

The public source code repositories are listed in the [Quollix GitHub organization](https://github.com/orgs/quollix/repositories). This page groups them by their role in the ecosystem.

* Foundational standalone repositories
  * **work**: development tooling suite
  * **taskrunner**: CI task handling library
  * **deepstack**: logging library
* Shared Quollix libraries
  * **common**: shared logic used by Quollix applications
* Quollix applications
  * **quollix**: main Quollix server application
  * **store**: central app store server, available at `https://store.quollix.org`
* Public presence
  * **website**: static website and documentation, available at `https://quollix.org`
