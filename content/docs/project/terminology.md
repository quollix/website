---
title: "Terminology"
---

This article defines Quollix-specific terms and preferred wording for website content.

| Term                    | Description                                                                                                                                         | Avoid                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Administrator           | Person who administers a Quollix server.                                                                                                            | Admin, hoster. Use "Quollix administrator" only when needed to avoid ambiguity. |
| App                     | Installed or installable service as seen by Quollix users, for example Nextcloud or Vaultwarden.                                                    | Application (software)                                                          |
| App definition          | A Docker Compose YAML that follows the [Quollix app definition conventions]({{< relref "docs/project/app-store/app-definition-conventions.md" >}}). | Docker Compose YAML when app definition is more precise                         |
| App maintainer          | Person or organization publishing app definitions in the [App Store]({{< relref "docs/project/app-store/_index.md" >}}).                            | Maintainer                                                                      |
| Authorization code flow | Browser-based OIDC sign-in flow where an app uses OIDC client credentials to authenticate with an OIDC provider.                                    | -                                                                               |
| Main service            | The service in an app definition whose name matches the app name. It exposes `quollix.port`, accepts HTTP requests, and serves the app's web UI.    | -                                                                               |
| OIDC client             | Application or service that lets users sign in through an OIDC provider.                                                                            | Client, app, service when the OIDC role should be clear                         |
| OIDC provider           | Service that authenticates users for OIDC sign-in.                                                                                                  | Identity provider, authentication provider, auth provider                       |
| Quollix maintainer      | The person maintaining the Quollix project.                                                                                                         | Maintainer                                                                      |
| Quollix server          | Server that runs Quollix.                                                                                                                           | Quollix instance, node                                                          |
| Quollix user            | Person with an account on a Quollix server who uses installed apps or account features.                                                             | -                                                                               |
| Server                  | Physical or virtual machine that runs software or accepts network connections.                                                                      | Node                                                                            |
| Service                 | Service entry in a Docker Compose YAML.                                                                                                             | Container when referring to the Compose service definition                      |
| Side service            | Any service in an app definition other than the main service.                                                                                       | -                                                                               |
| Sign-in                 | User authentication action.                                                                                                                         | Login, log in                                                                   |
| Update                  | Preferred term for changing Quollix, or an app to a newer version.                                                                                  | Upgrade, unless used for third-party software terminology.                      |
| Right arrow             | Use the right arrow symbol when an arrow is needed, for example `Apps → SSO`.                                                                       | `->`, `>`                                                                       |
